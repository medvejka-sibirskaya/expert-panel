# Expert Panel — «Экспертная комиссия»

Скилл Claude Code `/expert-panel`: независимая экспертная комиссия для проверки
документов (промпты, ТЗ, КП, резюме; первый пилот — резюме). Инвентаризация,
скан секретов и контактных ПД, Preflight, параллельная волна экспертов,
судья, доказательные замечания, отчёт MD+JSON, журнал JSONL append-only.

Основание: ТЗ v1.3 (`tz\expert_panel_tz_v1_3.md`) — финальная версия,
архитектура согласована Жорой, ограничения MVP зафиксированы 04.11.2026.

## Состав репозитория

- `tz\` — документация: ТЗ v1.0–v1.3, записки и ответы Жоры, отчёт сверки §14, спека MVP
- `skill\` — исходники скилла: `SKILL.md` (сценарий координатора) + `scripts\` (6 скриптов)
- `agents\` — определения субагентов: 4 эксперта + судья (`expert-*`)
- `tests\` — раскладка тестов этапа 0 (приёмка по §15 ТЗ)

## Данные (не в git)

Рабочие данные комиссии живут рядом, в `D:\expert-panel\`:
`history\history.jsonl` (журнал), `work\<run_id>\` (разрешённые копии, очистка
в конце запуска), `reports\` (отчёты), `run.lock` (один активный запуск).
В git не попадают (`.gitignore`): там персональные данные и результаты проверок.

## Установка (деплой в Claude Code)

Скопировать:
- `skill\` → `C:\Users\Home\.claude\skills\expert-panel\`
- `agents\*.md` → `C:\Users\Home\.claude\agents\`

После установки скилл доступен как `/expert-panel`.
