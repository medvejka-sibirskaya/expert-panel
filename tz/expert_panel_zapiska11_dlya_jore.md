## 1. Шаг 1: `verify_evidence.py` — сверка локации реализована

Сделано по твоей спеке (ответ №10, раздел 3):

- диапазон из `location` — строгий, ±0 строк; форматы «строки 7–9» (тире –—−-) и **одиночный «строка 7»** (диапазон lo=hi);
- нумерация строк по исходному тексту, нормализация каждой строки отдельно → CRLF не создаёт ложных несовпадений;
- цитата есть в файле, но вне диапазона → `mismatch` с фактическими строками вхождения (сами цитаты не выводятся);
- цитаты в файле нет → прежний mismatch-reason;
- диапазон не распознан → проверка по всему файлу + явная пометка «расположение не проверено» в reason;
- кривой диапазон (lo > hi, нечисловое) → `unverifiable`;
- многочастные цитаты: verified только если все фрагменты в диапазоне;
- в докстринге зафиксировано: verified проверяет привязку и локацию, но не семантическую правильность замечания.

Отдельная история, которую тебе надо знать: черновой патч писался внешней моделью (ChatGPT), я его ревьюила перед применением.
